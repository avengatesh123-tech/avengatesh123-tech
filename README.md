## About

I design and build data pipelines — streaming and batch — from raw ingestion through to analytics-ready gold layers. My approach is hands-on: build the pipeline, break it deliberately, then fix it properly, so I understand failure modes rather than just the happy path.

Current focus areas: **Kafka + Spark Structured Streaming + PostgreSQL** medallion architectures, containerized with Docker, and SQL query optimization — indexing strategy, SARGability, JOIN algorithms, and window functions.

Currently seeking **remote data engineering internships**, ideally with startups.
